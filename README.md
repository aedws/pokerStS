# pokerStS 🔫🃏🎲

**포커 족보로 데미지를, 카드 무늬로 속성을, 주사위로 장전을 정하는 SF 카우보이 덱빌딩 로그라이크.**
(슬레이 더 스파이어 × 발라트로 × 총·탄환)

전체 게임 설계는 [`GAME_DESIGN.md`](./GAME_DESIGN.md) 참고.

## 지금 구현된 것 (런 루프)

- **분기 맵** (전투 / 엘리트 / 휴식 / 보스) — 노드를 골라 탑을 오른다
- **덱 특화 루프**: 전투 승리 = **카드 획득**(3장 중 택1), 휴식 = **회복 또는 카드 제거**
- **상태 지속**: HP · 덱 · 레벨/XP 가 전투 사이에 이어진다 (보스 처치 = 런 클리어)
- **1D6 장전** → 눈이 곧 **장전 수 · 선공 · 데미지 보너스** (낮으면 빠르고 적게, 높으면 세고 느리게)
- **포커 족보 판정** (하이카드~로열 플러시, 칩×배수)
- **카드 무늬 = 속성** (♥화염 ♦냉기 ♠번개 ♣독), 혼합 무늬는 **비례 분배**
- **적 상성** (약점/저항/면역) 과 **상태이상** (화상·빙결·감전·독), 깊이별 난이도 스케일
- **재장전 크리티컬** (같은 눈 연속), **선공 무력화**
- **무기 3종** (리볼버 / 소총=단일무늬 특화 / 샷건=전체 대상)
- 모바일 우선 UI + 타격 이펙트(플로팅 데미지·흔들림·플래시)

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm test         # 엔진/전투 유닛 테스트
```

## 구조

```
src/
  engine/     # 순수 게임 규칙 (UI 무관, 테스트 대상)
    cards.ts        # 카드/덱/무늬→속성
    poker.ts        # 족보 판정 + 칩/배수
    dice.ts         # 1D6 → 장전/선공/데미지
    element.ts      # 속성 상성 · 비례 분배
    damage.ts       # 최종 데미지 공식
    enemies.ts      # 적 정의 (약점/저항) + 스케일 인카운터
    weapons.ts      # 무기 규칙
    progression.ts  # XP/레벨
    map.ts          # 분기 맵 생성
  state/
    gameStore.ts    # Zustand 런(맵/덱/HP) + 전투 상태머신
  ui/
    App.tsx         # 인트로/맵/전투/보상/휴식/결과 화면
  styles.css        # SF 카우보이 테마
```
